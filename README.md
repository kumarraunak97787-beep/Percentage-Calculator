# Student Result Calculator — Flask + 3D Animated UI

## Run

1. Open this folder in VS Code.
2. Open Terminal.
3. Install Flask:

    pip install -r requirements.txt

4. Start the server:

    python app.py

5. Open:

    http://127.0.0.1:5000

## Features

- User enters student name.
- User enters their own subject names.
- User enters marks for each subject.
- Python calculates total marks.
- Python calculates percentage.
- Python calculates grade.
- Python calculates PASS/FAIL.
- Responsive 3D animated CSS UI.
- Animated 3D cubes and floating glowing orbs.
- Flask POST form handling.
